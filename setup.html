JARVIS OMEGA

Einrichtung des privaten Gedächtnisses · 2 Minuten · kostenlos

1Datenbank verbinden (ein Schritt)

  1. Öffnen Sie Vercel → jarvis → Storage.
  2. Tippen Sie auf Create Database und wählen Sie Neon (Serverless Postgres). Falls nicht da: Supabase.
  3. Continue → Plan Free → Region Frankfurt → Create.
  4. Beim Fenster Connect Project: Projekt jarvis, alle Umgebungen angehakt → Connect.
  5. Schreiben Sie mir „fertig“ – ich starte JARVIS neu. Tabellen legt JARVIS selbst an.

Die Supabase-Einträge von vorhin brauchen Sie nicht mehr.

2Face ID einrichten

Öffnen Sie JARVIS, tippen Sie auf den Mond → Tresor öffnen → Face ID einrichten. Ab dann öffnet nur Ihr Gesicht den Tresor.

Optional: eigener Tresor-Schlüssel (noch stärker)

Ohne diesen Schritt wird der Schlüssel aus dem Datenbank-Passwort abgeleitet. Mit eigenem Schlüssel sind Ihre Daten auch dann unlesbar, wenn jemand Datenbank und Passwort hätte. Nur vor dem ersten Eintrag setzen – später gesetzt, werden alte Einträge unlesbar.

In Vercel als VAULT_KEY eintragen (Production angehakt).
