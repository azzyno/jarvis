JARVIS OMEGA

Einrichtung des privaten Gedächtnisses · ca. 10 Minuten · kostenlos

1Supabase-Projekt anlegen

  1. Öffnen Sie supabase.com und melden Sie sich mit Continue with GitHub an.
  2. Tippen Sie auf New project. Name: jarvis. Region: Central EU (Frankfurt) oder Zürich, falls angeboten.
  3. Ein Datenbank-Passwort wird verlangt: Lassen Sie es mit Generate erzeugen. Sie brauchen es nicht – schicken Sie es niemandem.
  4. Create new project – etwa 1 Minute warten.

2Tabellen erstellen

Kopieren Sie diesen Befehl, öffnen Sie im Projekt links SQL Editor, fügen Sie ihn ein und tippen Sie auf Run.

3Geheimen Tresor-Schlüssel erzeugen

Damit wird Ihr Gedächtnis verschlüsselt. Er entsteht nur hier auf Ihrem iPhone und wird nirgends gespeichert.

Nur in Vercel einfügen – nie in einen Chat oder Screenshot. Geht er verloren, sind die Einträge nicht mehr lesbar.

4Fünf Einträge in Vercel

Öffnen Sie Vercel → jarvis → Environment Variables und legen Sie an:

  1. VAULT_KEY = der Schlüssel aus Schritt 3
  2. OWNER_EMAIL = Ihre E-Mail-Adresse (nur damit dürfen Sie sich anmelden)
  3. SUPABASE_URL = in Supabase: Project Settings → Data API → Project URL
  4. SUPABASE_ANON_KEY = Project Settings → API Keys → Publishable key (oder „anon public“)
  5. SUPABASE_SERVICE_KEY = gleiche Seite → Secret key (oder „service_role“) – streng geheim

Danach in Vercel Deployments → ⋯ → Redeploy.

5Anmelde-Link erlauben

  1. In Supabase links Authentication → URL Configuration.
  2. Site URL: https://azzyno.github.io/jarvis/ → Save.
  3. Unter Redirect URLs dasselbe hinzufügen.
